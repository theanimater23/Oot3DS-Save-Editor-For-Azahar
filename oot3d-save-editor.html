Ocarina of Time 3D

Save Editor
◆

Edit a real OoT3D save file right in your browser — rupees, hearts, keys, and even which individual Gold Skulltulas you've collected. Nothing you upload here leaves your computer.

  1. Find the save file. In Azahar, right-click the game in your game list and look for something like Open Save Data Location — that opens a folder with your save file in it. Copy it somewhere easy to find, like your Desktop.
  2. Make a spare copy. Duplicate that file and rename the copy "backup" before you touch anything — if an edit ever goes wrong, this is how you undo it.
  3. Load it below and change whatever you like. Every field updates instantly and safely — you can't break anything just by typing.
  4. Download the edited file — it's saved as a new file, your original is never touched. Copy the new file into the save folder from step 1, replacing the original file there, then load your save in the game.

Click to choose a file, or drop it here.

The tool scans the whole file for save slots — it works whether you give it a single decrypted slot or the full save container.
